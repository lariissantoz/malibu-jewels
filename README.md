# 💎 Malibu Jewels 

> Loja virtual desenvolvida em React, consumindo dados da Fake Store API, estilizada com PrimeReact e utilizando PrimeFlex para um layout totalmente responsivo.

---

## ✨ Sobre o Projeto
A **Malibu Jewels** é uma vitrine de joias inspirada nas vibrações de verão e no estilo de Malibu. O projeto integra o consumo de API REST, gerenciamento de estado e componentes de UI reutilizáveis.

---

## 🚀 Tecnologias Utilizadas
* **React** (Create React App)
* **PrimeReact** (Componentes de UI e `<Card>`)
* **PrimeFlex** (Grid e utilitários responsivos)
* **Axios** (Requisições HTTP para a Fake Store API)
* **CSS3** (Estilização e identidade visual personalizada)

---

## 🛠️ Funcionalidades
* **Consumo de API:** Busca dinâmica de produtos na categoria *jewelery* da Fake Store API via Axios.
* **Coleção Exclusiva:** Mescla produtos da API com uma coleção própria de destaque (*Coleção Pôr do Sol*).
* **Formulário de Cadastro:** Permite adicionar novas joias diretamente à vitrine em tempo real.
* **Sacola e Favoritos:** Controle de quantidade, subtotal formatado em reais (`R$`) e sistema de favoritos.
* **Responsividade:** Layout adaptável com PrimeFlex.
